# 清理与合并 + 命名与内聚 + 验证清单

## 清理与合并

| 操作 | 说明 |
|------|------|
| 删除注释代码 | 堆积的注释块一律清掉 |
| 移除未用导入/变量 | 用 lint 工具检测 |
| 删除孤立文件 | 不再被导入的文件 |
| 清理 console.log | 不再需要的调试代码 |
| 合并 3+ 相似函数 | 参数化统一 |
| 合并相同逻辑 | 提取为函数 |

## 命名与内聚

- 模糊命名改自描述性命名
- 相关函数按职责分组，不按大小
- 导入顺序：外部库 → 内部模块 → 样式/类型
- export 语句统一放在文件末尾

## 验证清单

1. 无断掉的 import——所有提取的文件正确导入
2. 无循环依赖——用 `madge` 或人工检查
3. 测试通过——有测试套件则运行
4. 构建成功——`npm run build` 或 `npm run dev`
5. 功能不变——UI/逻辑与重构前一致
6. Lint 通过——`npm run lint`
