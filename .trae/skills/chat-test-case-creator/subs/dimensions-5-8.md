# 测试维度 5-8（多轮对话 / 卡片渲染 / 角色权限 / 边界异常）

## 5. 多轮对话（DIALOG）

| 子类 | 重点 |
|------|------|
| DIALOG-01~05 | 上下文保持：连续多轮相同话题不丢失 |
| DIALOG-06~10 | 话题切换：主动切换话题后上下文更新 |
| DIALOG-11~15 | 历史回溯：滚动加载历史、新消息自动滚动 |

```markdown
### TC-DIALOG-01：多轮连续对话上下文保持

| **测试ID** | TC-DIALOG-01 | **优先级** | P0 |
| **前置条件** | 用户已登录 |
| **测试步骤** | 1. "北京有哪些在拍的房产项目"\n2. AI 回复标的列表\n3. "第一个项目的起拍价是多少"\n4. AI 回复具体价格\n5. "它的保证金要求呢" |
| **预期结果** | 1. 第二轮正确引用第一轮搜索结果\n2. 第三轮正确引用第二轮提到的标的\n3. 逻辑一致，无张冠李戴 |
| **验证方式** | 人工判断 + SSH 日志确认 context 拼接 |

### TC-DIALOG-02：话题切换后上下文重置

| **测试ID** | TC-DIALOG-02 | **优先级** | P1 |
| **前置条件** | 已完成一轮搜标对话 |
| **测试步骤** | 1. 发送搜标消息并得到回复\n2. 发送完全不同的话题\n3. 观察 AI 回复 |
| **预期结果** | 1. AI 能识别话题切换\n2. 新回复与旧标的无关\n3. 前一轮上下文可回溯查看 |
```

## 6. 卡片渲染（CARD）

| 子类 | 重点 |
|------|------|
| CARD-01~05 | 标的卡片：搜索结果展示、点击跳转、数据完整 |
| CARD-06~10 | 特殊卡片：尽调报告、出价分析、政策解读 |
| CARD-11~15 | 交互验证：卡片内按钮、链接、收藏操作 |

```markdown
### TC-CARD-01：标的卡片渲染正确性

| **测试ID** | TC-CARD-01 | **优先级** | P0 |
| **前置条件** | 用户已登录 |
| **测试步骤** | 1. 发送搜标消息\n2. 等待 AI 回复\n3. 观察标的卡片 |
| **预期结果** | 1. 标题、起拍价、标的类型等关键字段完整\n2. 布局正常，无截断/溢出\n3. 点击卡片跳转标的详情页 |
```

## 7. 角色权限（ROLE）

| 子类 | 重点 |
|------|------|
| ROLE-01~05 | 游客：未登录的功能限制 |
| ROLE-06~10 | 普通用户：已登录未实名 |
| ROLE-11~15 | 实名用户：已通过实名验证 |
| ROLE-16~20 | 管理员：额外权限 |

```markdown
### TC-ROLE-01：非实名用户看不到出价分析

| **测试ID** | TC-ROLE-01 | **优先级** | P1 |
| **前置条件** | 用户已登录但未实名 |
| **测试步骤** | 1. 长按关联标的的消息\n2. 观察菜单选项\n3. 检查底部功能入口 |
| **预期结果** | 1. 菜单不含「出价分析」\n2. 底部功能入口不含「新增拍卖标的」\n3. 底部显示：我的尽调 / 我的竞价分析 / 我的出价 / 我的政策研判 |
```

## 8. 边界异常（EXC）

| 子类 | 重点 |
|------|------|
| EXC-01~05 | 输入异常：空输入、超长输入、特殊字符、纯表情 |
| EXC-06~10 | 网络异常：弱网、断网重连、超时 |
| EXC-11~15 | 操作异常：快速连点、页面切换后返回、并发请求 |

```markdown
### TC-EXC-01：空输入处理

| **测试ID** | TC-EXC-01 | **优先级** | P1 |
| **前置条件** | 用户已登录 |
| **测试步骤** | 1. 输入框为空\n2. 点击发送按钮 |
| **预期结果** | 1. 发送按钮禁用\n2. 不发送 API 请求\n3. 无异常报错 |

### TC-EXC-02：超长输入处理

| **测试ID** | TC-EXC-02 | **优先级** | P2 |
| **前置条件** | 用户已登录 |
| **测试步骤** | 1. 输入超过 2000 字的文本\n2. 点击发送 |
| **预期结果** | 1. 输入框有字符数限制提示\n2. 超过限制时截断或阻止发送\n3. 发送成功时服务端正常处理 |
```
