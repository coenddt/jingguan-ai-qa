# 目录结构 + 文档头模板 + 测试用例格式

## 目录结构

```
doc/testcase/
├── <YYYY>/
│   ├── <MM>/
│   │   ├── 未处理-xxx测试用例.md    // 首次创建用 -test-cases 后缀
│   │   └── 未处理-xxx回归测试.md    // 回归测试用 -regression-test 后缀
│   └── ...
└── README.md (可选)
```

文档命名：中文功能/模块名，同一功能多次迭代加 v2/v3 版本号。

## 文档头模板

```markdown
# {功能名称} — 测试用例

> 版本：v{version} | 日期：{YYYY-MM-DD} | 状态：{draft/ready/reviewed}
> 关联文档：[设计文档]({link-to-design-doc})
> 测试范围：{功能模块简要描述}

---

## 测试环境

| 维度 | 说明 |
|------|------|
| 前端 | 微信小程序 - 开发版/体验版 |
| 后端 | 云服务器 - 测试环境 API |
| 工具 | 微信开发者工具 Network 面板 / SSH 服务器日志 |
| 数据 | 专用测试账号 + 预设测试数据 |

---

## 测试维度总览

| 维度 | 覆盖内容 | 用例数 |
|------|---------|-------|
| SSE 流式协议 | 连接、事件、完成、中断、重连 | {N} |
| 意图识别 | 分类准确性、子意图引导、降级 | {N} |
| 上下文指示器 | 默认状态、切换、清除、参数透传 | {N} |
| 长按菜单 | 可见性规则、功能入口、操作验证 | {N} |
| 多轮对话 | 上下文保持、话题切换、历史回溯 | {N} |
| 卡片渲染 | 标的卡片、搜索结果、数据绑定 | {N} |
| 角色权限 | 游客/实名/管理员的对话行为差异 | {N} |
| 边界异常 | 空输入、超时、网络错误、连点 | {N} |
| **合计** | | **{N}** |
```

## 测试用例格式

```markdown
### TC-{类别编号}-{序号}：{测试场景标题}

| 字段 | 值 |
|------|-----|
| **测试ID** | TC-{类别}-{序号} |
| **优先级** | P0/P1/P2 |
| **关联需求** | {需求ID或链接} |
| **前置条件** | {需要满足的前提} |
| **测试步骤** | 1. {步骤1}\n2. {步骤2}\n3. {步骤3} |
| **预期结果** | 1. {结果1}\n2. {结果2} |
| **验证方式** | {人工/Network日志/SSH日志/自动化} |
```
