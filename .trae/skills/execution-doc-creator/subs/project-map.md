# 项目端与角色全景图

## 项目一：今天吃啥呢AI生活助手

### 端定义

| 端 | 目录 | 形态 | 说明 |
|:---|:---|:---|:---|
| 生活助手小程序 | `miniapp/` | 微信小程序（C端） | 用户日常使用的移动端，聊天/提醒/设置 |
| 生活助手后端 | `server/` | Express API 服务 | 业务逻辑、数据存储、AI 调度 |

> 该项目无 PC 管理后台，无独立图片服务。

### 角色定义

| 角色 | 英文标识 | 典型场景 | 权限范围 |
|:---|:---|:---|:---|
| **普通用户** | `user` | 已登录的日常使用者 | 聊天对话、设置偏好、管理提醒、上传图片、语音输入、查看个人中心 |
| **游客** | `guest` | 未登录/首次打开 | 仅可浏览欢迎页和基础介绍，无法使用聊天等核心功能，引导登录 |

### 角色 × 端差异矩阵

| 功能维度 | 普通用户（小程序） | 游客（小程序） | 后端差异 |
|:---|:---|:---|:---|
| 首页 | 进入聊天页 | 进入欢迎页，引导登录 | `GET /api/auth/check` 鉴权中间件拦截 |
| 对话 | 完整多轮对话、多模态 | 不可用 | 需登录态 |
| 提醒 | 增删改查提醒 | 不可用 | 需登录态 |
| 个人中心 | 查看/编辑资料 | 不可用 | 需登录态 |
| 设置 | 模型选择、通知偏好 | 不可用 | 需登录态 |
| 语音输入 | 可用 | 不可用 | 需登录态 |
| 图片识别 | 可用 | 不可用 | 需登录态 |

## 项目二：漉金Core专业拍卖平台

### 端定义

| 端 | 目录 | 形态 | 说明 |
|:---|:---|:---|:---|
| 拍卖小程序 | `miniapp-finance/` | 微信小程序（C端） | 用户浏览项目、参与竞拍、收藏订阅 |
| 管理后台 | `web-saas/` | React PC 网页（B端） | 平台管理、项目审核、数据统计 |
| 拍卖后端 | `server-finance/` | Express API 服务 | 业务逻辑、数据存储、AI 调度、拍卖引擎 |
| 图片服务 | `server-image/` | 独立 Express 微服务 | 图片压缩、格式转换、水印处理 |
| 公共模块 | `server-shared/` | npm 共享包 | LLM 路由、Embedding 客户端、日志等 |

### 角色定义

| 角色 | 英文标识 | 典型场景 | 权限范围 |
|:---|:---|:---|:---|
| **买家 / 投资人** | `buyer` | 浏览项目、参与竞拍、尽职调查 | 项目搜索、文档查看、收藏、订阅、竞拍出价、聊天问答 |
| **卖家 / 资产方** | `seller` | 发布资产、管理项目、查看竞拍进展 | 项目发布、资料上传、查看买家意向、竞拍状态管理 |
| **平台管理员** | `admin` | 后台管理、审核、用户管理 | 项目审核、用户管理、数据统计、系统配置、知识库管理 |
| **游客 / 未登录** | `guest` | 未登录、首次访问 | 仅浏览公开项目列表和基本信息，无法参与竞拍、收藏、订阅 |

### 角色 × 端差异矩阵

| 功能维度 | 买家（小程序） | 卖家（小程序） | 管理员（PC后台） | 游客（小程序） | 后端差异 |
|:---|:---|:---|:---|:---|:---|
| 首页 | 项目列表 + 推荐 | 我的项目 + 发布入口 | 统计看板 | 公开项目列表 | 不同角色返回不同数据 |
| 项目浏览 | 全部已审核项目 | 自己发布的项目 | 全部项目（含待审核） | 仅公开可见项目 | 鉴权 + 数据过滤 |
| 项目发布 | 不可用 | 创建项目 + 上传资料 | 不可用 | 不可用 | 卖家专属 API |
| 项目审核 | 不可用 | 不可用 | 审核通过/驳回 | 不可用 | 管理员专属 API |
| 智能问答 | 针对可见项目问答 | 针对自己项目问答 | 知识库管理问答 | 不可用 | 按角色过滤上下文 |
| 资料查看 | 已审核项目资料 | 自己项目全部资料 | 全部资料 | 公开资料 | 按角色过滤 |
| 收藏 | 收藏项目 | 不可用 | 不可用 | 不可用 | 买家专属 |
| 订阅 | 订阅标的/公司 | 不可用 | 不可用 | 不可用 | 买家专属 |
| 竞拍出价 | 参与竞拍 | 查看出价列表 | 监控异常 | 不可用 | 买家/卖家/管理员各自视图 |
| 个人中心 | 个人信息 + 我的收藏/订阅 | 个人信息 + 我的项目 | 管理员设置 | 不可用 | 按角色返回不同数据 |
| 用户管理 | 不可用 | 不可用 | 用户列表/禁用/角色分配 | 不可用 | 管理员专属 |
| 数据统计 | 不可用 | 不可用 | 看板/图表/导出 | 不可用 | 管理员专属 |
