## 4. 详细执行契约（代码优先）

### 4.1 新增题 golden 契约

关键约束（来自 query_guard._verify_aggregate 与 query_policy）：
- 聚合算子白名单 `ALLOWED_MEASURES = {sum, avg, count, min, max}` → avg/min/max 合法
- 复合分组：groupBy 数组允许多字段（仅逐项校验在白名单内），无数量上限
- aggregate 排序键允许集 = groupBy 字段 ∪ 计算列 `op_field`（如 `avg_contractAmt`）
- 聚合字段必须数值型：CommercialLedger 的 contractAmt/income 为 float
- 只读承诺不变；新题 golden 必须在云端预检 execute 无异常（verify 不看数据行数）

```json
{"id": "n45", "q": "2026年各产品线各月份的签约金额合计",
 "expect": {"model": "CommercialLedger", "mode": "aggregate"},
 "golden": {"mode": "aggregate", "model": "CommercialLedger",
            "condition": {"year": {"$eq": 2026}},
            "groupBy": ["productLine", "month"],
            "measures": [{"op": "sum", "field": "contractAmt"}],
            "sort": {"sum_contractAmt": -1}, "limit": 50}},

{"id": "n46", "q": "2026年各季度各行业的签约金额合计",
```
