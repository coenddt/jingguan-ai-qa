# 语音输入接入豆包语音识别 2.0（双向流式）

## Context（为什么改）

当前语音输入用的是浏览器内置 `SpeechRecognition`/`webkitSpeechRecognition`（[InputBar.tsx](file:///f:/独立开发者/项目/AI创新中心项目/web-front/src/features/qa/InputBar.tsx#L29-L65)）。它底层直连 Google 云端语音服务，不经过页面 HTTP 请求，国内网络无法访问 → 录音几秒后触 `onerror` → 弹"语音识别失败，请重试"，实际未发页面网络请求。用户在 Network 面板看不到请求是正常的，本质是连的是墙外服务。

目标：改为走项目自有后端，接**火山豆包语音识别 2.0（双向流式优化版** **`bigmodel_async`）**，实现边说边出字（流式回填输入框）。用户已提供 API Key：`api-key-20260421205439`。

## 技术链路

```
前端 AudioWorklet 采 PCM(16k/16bit/mono)
  → 原生 WebSocket 二进制上行到 后端 /api/asr/ws（携带登录 Cookie 鉴权）
    → 后端用 websockets 库连 火山 wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async
      → 以 SendAudio 帧转发音频；火山 FullResponse 返回 result[].text
    → 后端把识别文本经同一前端 ws 文本帧实时下行
  → 前端累积识别文本 → 流式填入 textarea
```

火山侧协议要点：

- URL：`wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`（双向流式·优化版）

- 鉴权头（新版控制台）：`X-Api-Key`、`X-Api-Resource-Id=volc.seedasr.sauc.duration`（2.0 小时版，推荐）、`X-Api-Request-Id=<UUID>`、`X-Api-Sequence=-1`（固定）

- 二进制帧 = V3 协议（与参考 `VolcEngineWebSocketClient.js` 同一套）：Header(4B) + \[Event 4B + SessionIdLen 4B + SessionId + MetaLen 4B + Meta]（带事件号的 JSON/二进制包）

- 上行事件：StartSession=100（JSON：audio+request 配置）、SendAudio=200（二进制音频）、FinishSession=102

- 下行事件：ConnectionStarted=50、SessionStarted=150、SessionFinished=152、SessionFailed=153、FullResponse=0b1001（识别结果，取 `result[].text`）。q 包可能返回 `result_type=full`（全量）或 `single`（增量），按 `final`/text 累积。

- 音频格式：`format=pcm, codec=raw, rate=16000, bits=16, channel=1`；分包建议 200ms（约 6400B/包）

- 请求参数：`request.model_name=bigmodel`、`enable_itn=true`、`enable_punc=true`、`enable_ddc=true`（顺滑）

参考实现：`F:\module-server\rts-module-partner\server\services\modulePartner\api\AIModelChatTtsStream\VolcEngineWebSocketClient.js`（帧编解码/事件号的 JS 版，翻译为 Python）。本项目后端 TTS 相关文件为同款分层模板。

### 3. 帧编解码工具

- 新增 `server/app/services/asr_protocol.py`：V3 二进制帧的 **构造**（StartSession=100 / SendAudio=200 / FinishSession=102）与 **解析**（读取 Header 版本/头部长度/messageType/flags/序列化/压缩，抽取 payload、gzip 解压、JSON 反序列化，识别事件号）。用 `struct`/`zlib` 实现。翻译自参考 JS。

### 4. 与火山的双向会话服务

- 新增 `server/app/services/asr_service.py`（仿 `tt_service.py`）：

  - `open_session(api_key, request_id, queue_sink)`：用 `websockets.connect` 带鉴权头连火山，发 StartSession 帧；校验 SessionStarted(150)。

  - 提供 `send_audio(bytes)` / `finish()`：以 SendAudio / FinishSession 帧上行。

  - 后台读包任务 `_reader()`：解析帧，FullResponse 取出 `result[].text`（含全量/增量、final 语义）→ 放入 `asyncio.Queue` 供 router 下行给前端；SessionFailed(153)/异常 → 队列放错误。

  - 关闭顺序：前端 end → FinishSession → 等 SessionFinished(152) → 关连接。

### 5. WebSocket 路由

- 新增 `server/app/routers/asr_ws.py`：

  - `@router.websocket('/api/asr/ws')`。

  - 鉴权：从 `websocket.headers` 的 Cookie 校验登录（复用 `app.auth` 的会话校验逻辑；ws 同源会自动带 Cookie，与现有受保护 HTTP 组一致的鉴权基线）。

  - 流程：accept → 前端首个 JSON `{action:'start'}` → 建火山会话 → 循环 `receive`：bytes=音频→`send_audio`；text=控制（stop/end）→`finish`；同时把队列里识别文本以文本帧 `{type:'transcript', text, final:true|false}` 下行 → 收到 SessionFinished/前端断开 → 清理并向后端吐一条自动反馈日志（追踪 use-asr 事件）。

  - 异常/越界按守卫思想：wrap 错误，向前端发 `{type:'error'}`，并记录反馈（触发原因/命中的防护）。

### 6. 注册

- [main.py](file:///f:/独立开发者/项目/AI创新中心项目/server/app/main.py#L68-L78)：import `asr_ws` 并 `include_router` 到 `_protected` 组（WS 鉴权由 asr\_ws 内自定义，但统一挂受保护组以保持路由组织一致）。

## 前端改动（web-front/）

### 重写 `useVoiceInput`（[InputBar.tsx](file:///f:/独立开发者/项目/AI创新中心项目/web-front/src/features/qa/InputBar.tsx#L29-L65)）

- 移除 `SpeechRecognition` 依赖；`start(onText)` 改为：

  1. `navigator.mediaDevices.getUserMedia({audio})` 取麦克风；
  2. 建 `AudioContext` + `AudioWorkletNode`（PCM 采集），利用 Web Audio 内置录入、`ScriptProcessor`/worklet 内做 16k 降采样 + 编码 int16（小端）；**无第三方依赖**；
  3. 按约 100–200ms 累积生成 PCM 帧，通过 `new WebSocket((location.protocol==='https:'?'wss':'ws')+'://'+location.host+'/api/asr/ws')` binary 发送（ws 同源握手自动带登录 Cookie）；
  4. 收到 `{type:'transcript', text, final}`：`final` 为真→固化追加到已确认文本；`final` 为假→替换当前句中间稿。通过 `start` 的回调把"已确认 + 中间稿"合成字符串流式写入 `textarea`（复用现有 `voiceInput` 回调，InputBar 已把结果 append 到文本）。
  5. 停止/出错：发 `{action:'end'}`，合并最终文本；`onerror` 仍复用 `showSnackbar`，但文案改为更准确的中文提示（"语音识别服务连接失败，请重试"）。

- 保持 `sttEnabled` 开关语义不变（AppConfig 里"语音转文字"开关 + `/api/config` 下发，[useConfigStore.ts](file:///f:/独立开发者/项目/AI创新中心项目/web-front/src/store/useConfigStore.ts) 不动）。

- 新增清理：组件卸载/断开时关 ws、停 AudioContext。
