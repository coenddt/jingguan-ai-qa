## 测试用例 4：run_as_internal 异步协程契约 ✅

首次按旧写法 `run_as_internal(lambda: store.insert(...))` 实测失败：

```
TypeError: 'coroutine' object is not subscriptable
RuntimeWarning: coroutine 'insert' was never awaited
```

改用 `async def _write(): return await store.insert(...)` 后 `await run_as_internal(_write)` 成功（INSERTED）。

**缺陷根因：** `run_as_internal` 用 `inspect.iscoroutinefunction(fn)` 判断，`lambda` 非协程函数 → 走 `return fn()` 返回未 await 的协程，**insert 实际从未执行、反馈不落库**。已在 `services/auto_feedback.py` 统一改为 async 内层函数并重传。

**结论与预期一致：** 新写法写入链路成功；旧写法被暴露拦截，形成回归保护。
